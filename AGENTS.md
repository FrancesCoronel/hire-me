# AGENTS.md

Guidance for AI coding agents (Claude Code, Copilot, Codex, and others) working in this repository. Humans should read [CONTRIBUTING.md](CONTRIBUTING.md).

## What this repo is

A guide to landing a tech job, published with [docsify](https://docsify.js.org) at [francescoronel.github.io/hire-me](https://francescoronel.github.io/hire-me/). All content is Markdown in `docs/`, organized by stage: `01-prepare`, `02-search`, `03-apply`, `04-interview`, `05-accept`. Navigation lives in `docs/_sidebar.md`.

## Adding content or resources

- Put it in the stage it belongs to. Each stage's `README.md` is its landing page (the sidebar links it as "Step N"); other files in the stage are subpages. If you add a new page, add it to `docs/_sidebar.md`.
- Follow the page's format: most resources are a `### Name` heading under a `## Group`, then a sentence that links it; list sections (like Job Boards) use one `- [Name](url)` line. Keep headings and list items in a group alphabetized.
- Some pages (`docs/01-prepare/README.md`, `docs/02-search/README.md`) have a `<!-- TOC depthFrom:2 -->` block, generated by the VS Code Markdown TOC extension. When you add or rename a heading there, update the TOC block by hand to match.
- Every resource needs a working link and a sentence on what it offers job seekers.
- Keep list items alphabetized. Use 2 spaces, no tabs, no trailing whitespace.
- No affiliate links, paywalled courses or self-promotion without saying so in the PR.

## Pull requests

- One topic per PR, with a clear title like `Add salary negotiation resource`.
- Fill in the PR template, including the checklist. PRs that skip the template may be closed.
- Agents don't add themselves to the Credits list in `README.md`; leave that checklist item unchecked.
- Don't edit workflows or Dependabot config in a content PR.

## Checks

CI comes from the shared workflows in [FrancesCoronel/workflows](https://github.com/FrancesCoronel/workflows) (Markdown lint and link checks). Run the same checks before opening a PR:

```bash
npx markdownlint-cli2 "**/*.md" "#node_modules" "#.github"   # uses .markdownlint.json, same rules as CI
lychee --exclude workatastartup.com --exclude keyvalues.com docs/<changed-file>.md   # if lychee is installed
```

CI link-checks only the Markdown files a PR changes. `.editorconfig` sets the formatting rules (LF, 2 spaces, final newline, no trailing whitespace).

The `add-resource` skill (`.claude/skills/add-resource/`) walks through adding a resource.

To preview the site locally, run `npx docsify-cli serve docs` and open `http://localhost:3000`. Site config (theme, plugins, sidebar) is in `docs/index.html`; keep its CDN scripts pinned to a major version.
